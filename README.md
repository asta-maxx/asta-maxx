## Projects

### Karukon — Telegram Sentinel

A real-time AI-powered crypto-scam detection system built for the Tamil Nadu Cyber Crime Wing, awarded **1st Runner-Up at Tamil Nadu Police Hackathon 2024**.

The system monitors live Telegram traffic, classifies messages using an ensemble ML model (XGBoost + AdaBoost), and surfaces threats through a live dashboard — all in production.

**Stack:** Python · Django REST Framework · React · PostgreSQL · XGBoost · AdaBoost · Telegram API · Docker · Prometheus · Grafana

**Highlights:**
- 98% detection accuracy via strategic feature engineering on message metadata and content
- Full-stack production deployment with Django backend, React dashboard, and live Telegram API integration
- Containerised with Docker; monitored with Prometheus + Grafana

---

### ZDNS — Intelligent DNS Threat Filtering

A low-latency ML-powered DNS firewall that proactively blocks malicious domains in real-time using live threat intelligence feeds. Selected as a **National-Level Finalist at Smart India Hackathon 2023**.

**Stack:** Python · Scikit-learn · STIX/TAXII · Django REST Framework · React · PostgreSQL · AWS EC2 · Prometheus · Grafana

**Highlights:**
- Naïve Bayes classifier trained on DNS patterns for real-time malicious domain classification
- Automated threat intelligence ingestion from OTX/MISP platforms via STIX/TAXII protocols
- Deployed on AWS EC2 with full observability stack

---

### Autonomous AI Research Agent

A multi-agent system that autonomously researches any given topic — searches the web, synthesises findings across sources, and generates structured reports without human intervention mid-task.

**Stack:** Python · LangChain · CrewAI · FastAPI · Streamlit · Groq / OpenAI · ChromaDB

**Highlights:**
- Agent framework with tool-calling, persistent vector memory (ChromaDB), and multi-step planning via LangChain/CrewAI
- FastAPI backend; deployed as an interactive Streamlit web app
- Supports swappable LLM backends (Groq, OpenAI)
